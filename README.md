# TaxRocket Redesign Demo

A standalone **Next.js** demo project showcasing the redesigned TaxRocket filing experience. This project runs independently and does **not** require the original TaxRocket codebase.

It uses mock data stored in the browser via `localStorage` instead of a database, allowing you to test the complete filing flow from start to finish.

## Getting Started

```bash
npm install
npm run dev
```
